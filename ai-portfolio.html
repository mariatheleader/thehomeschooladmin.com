Daily Async Remote Jobs Automation (GitHub Actions + SendGrid)

  • What it does: GitHub Actions workflow that fetches remote job postings daily from RemoteOK API, filters for async-eligible roles, formats as HTML email, and sends via SendGrid—zero manual intervention.
  • Architecture: Python script + GitHub Actions scheduled workflow (cron) + SendGrid email API.
  • Demonstrates: CI/CD workflow design, API integration, scheduled automation, environment variables/secrets management, error handling, and rapid problem-solving (pivoted from Himalayas to RemoteOK when initial API wasn't accessible from GitHub runners).
  • Impact: Delivers 15+ curated job opportunities directly to inbox daily—a practical example of turning repetitive manual searching into a 30-second automated system.
  • Fully open-source and documented in GitHub—portfolio-ready demonstration of automation thinking applied to real-world workflow problems.
